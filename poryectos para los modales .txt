QuiriNotes — Gestor Académico Inteligente (WEB)

Plataforma web full-stack enfocada en la organización académica y gestión de contenido educativo. Desarrollada con Angular, PHP y MySQL, permite administrar cursos, unidades de aprendizaje, apuntes estructurados, tareas pendientes y recursos multimedia dentro de una experiencia moderna e intuitiva.

El sistema implementa una arquitectura SPA (Single Page Application) conectada mediante una API RESTful, integrando autenticación de usuarios, comunicación cliente-servidor y persistencia de datos en tiempo real. Además, incorpora módulos para gestión de notas tipo Cornell, administración de tareas académicas y consumo de APIs externas para recursos visuales.

El proyecto implementa una arquitectura desacoplada basada en HTTP y WebSockets, permitiendo conversaciones síncronas y respuestas en streaming en tiempo real.

El sistema utiliza un enfoque inspirado en RMI (Remote Method Invocation), centralizando la ejecución de métodos mediante un único endpoint capaz de despachar diferentes operaciones relacionadas con IA. Además, incorpora manejo de concurrencia, colas de procesamiento y comunicación bidireccional para optimizar la experiencia del usuario.
